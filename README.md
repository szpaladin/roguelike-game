# Roguelike 游戏

一款基于 HTML5 Canvas 的 Roguelike 类游戏，具有武器系统、升级机制和融合玩法。

## 🎮 游戏特性

- **武器系统**：多种武器类型和特性
- **武器融合**：独特的武器融合机制
- **敌人系统**：多样化的敌人类型
- **升级系统**：角色成长与技能提升
- **宝箱奖励**：随机掉落与奖励机制

## 🚀 如何运行

1. 克隆仓库或下载代码
2. 直接用浏览器打开 `index.html` 文件即可开始游戏
3. 无需任何构建工具或依赖安装

## 📁 项目结构

```
roguelike_game/
├── index.html              # 游戏入口
├── game.js                 # 核心游戏逻辑
├── weapon_fusion_config.js # 武器融合配置
├── enemy_config.js         # 敌人系统配置
└── style.css               # 样式文件
```

## 🎯 游戏说明

使用鼠标或键盘控制角色移动，击败敌人，收集奖励，升级武器！
